# RigCoach

Rowing rigging coach for iPhone. Measures oar angles, pitch, stretcher and boat level with the phone's sensors, works out what to change, and guides each adjustment step by step.

Open it at https://swemarathonrowing.github.io/RigCoach/ and tap **Share → Add to Home Screen**.

Rigging text and figures from the World Rowing (FISA) Coaching Development Programme handbooks, reproduced with permission from World Rowing.
